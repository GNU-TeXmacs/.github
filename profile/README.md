## What Is GNU TeXmacs

GNU TeXmacs is a structured scientific editor. You write a paper, a lecture note, or a thesis chapter you own, and the screen looks like the printed page while the file remains a tree of tags. GNU TeXmacs structured editor is that environment. GNU TeXmacs WYSIWYG math is how equations appear. GNU TeXmacs document tree is the outline. GNU TeXmacs scientific typeset is the PDF or print you actually hand over.

Authors look this up when they want TeX appearance without spending the day in backslashes, or when a notebook-style proof should live next to a plot from a session they already use. It is not Overleaf, not MathMagic’s plugin into InDesign, and not a replacement for a journal class you were sent if that journal still demands raw LaTeX.

Work on documents you write or were hired to edit. Keep styles with the title. Do not paste an entire publisher template you are not allowed to redistribute.

## Starting with GNU TeXmacs

Prerequisites: A PC you administer and a scientific text you already write or were hired to edit.

1. **Prepare:** Open a short note you own, not a publisher book, so the first session is yours.
2. **Configure:** Pick a style close to that note and set fonts GNU TeXmacs structured editor will keep.
3. **Test:** Type a section and a GNU TeXmacs WYSIWYG math display, then export a PDF you keep.
4. **Refine:** Use GNU TeXmacs document tree to move a theorem and confirm labels still resolve.
5. **Apply:** Grow the paper you own, adding sessions only if that workflow is yours.
6. **Maintain:** Archive the `.tm` with the PDF before a submission, and keep styles inside that title.
